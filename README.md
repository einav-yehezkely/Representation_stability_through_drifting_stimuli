# Representation stability through a drifting stimuli

### CelebA dataset is from
https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html

### ResNet50 model

Download the resnet model from:
https://github.com/cydonia999/VGGFace2-pytorch?utm_source=chatgpt.com

Place the downloaded file at:
extract_embeddings/resnet.py

### ResNet50 VGGFace2 weights

The pretrained ResNet50 weights are not included in this repository
due to their file size.

Download the pretrained VGGFace2 ResNet50 weights from:
https://drive.google.com/file/d/1gy9OJlVfBulWkIEnZhGpOLu084RgHw39/view

Place the downloaded file at:

extract_embeddings/resnet50_scratch_weight.pkl
